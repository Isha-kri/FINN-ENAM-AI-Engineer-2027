## Limitations

- RSS names can vary from the display name in the portfolio; unmatched rows are skipped rather than assigned by ticker substring. RSS coverage is a short recent window, not a historical archive.
- Yahoo is an unofficial public interface. Current code stores history but still requests a recent 3-month range on refresh; incremental range fetching is a follow-up improvement.
- The local source smoke does not imply continuous monitoring. Refresh is user initiated, and EOD triggers are evaluated only when a newer market session appears.
- Infosys has nine configured primary documents. The four initial ad-hoc examples have source links in the library (Cipla two, Coal India one, Trent one, BPCL one), but those additional PDFs have not been individually ingestion-smoke-tested. Other NSE tickers return a clear no-configured-documents state. The retrieval result is evidence, not a completed financial-analysis narrative.
- Results extraction currently covers only the verified Infosys Q2 FY27 consolidated statement: Revenue, PBT, PAT, and QoQ/YoY; EBITDA remains unavailable. Other issuer formats are not parsed. The four-call guidance workflow pairs one FY26 range with its later FY26 actual; FY27 outcomes are not yet available. No management background enrichment is claimed. Filing-category alerts match the deterministic category rules applied to ingested RSS filings, so classifier omissions or misclassification remain possible.
